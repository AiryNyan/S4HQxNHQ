작동원리
1. 심즈 실행 시 dll 파일이 텍스처를 후킹
2. 1024x2048 사이즈의 기본 텍스처의 픽셀을 그냥 2배로 키움
2-1. 이 작업에서 다른 텍스처 보간 같은 건 없어서 기본 텍스처 화질이 좋아지는 건 없습니다
